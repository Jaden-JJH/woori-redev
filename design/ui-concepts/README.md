# 우리동네 재개발 비서 UI 방향 시안

2026-09-29, 방향 선택용. 기존 앱 구현은 수정하지 않았습니다.

## 사용자 기준

- 40~60대 모바일 이용자
- 친근하고 생동감 있는 인상
- 여러 화면 시안을 비교한 뒤 구현 방향 선택

## 파일

- index.html: 별도 서버 없이 브라우저에서 열 수 있는 비교 화면
- comparison.png: 세 방향의 내 구역 화면 비교
- checklist-comparison.png: 세 방향의 상세 화면 비교
- a-home.png, b-home.png, c-home.png: 390x844 개별 홈 화면
- a-checklist.png, b-checklist.png, c-checklist.png: 390x844 개별 상세 화면
- large 접미사 이미지: 큰 글씨 상태
- validation.json: 렌더링 및 시안 상호작용 검사 결과

index.html?concept=a 형태로 개별 화면을 볼 수 있습니다. page=checklist를 추가하면 상세 화면으로 시작합니다.

## 방향 비교

| 방향 | 인상과 표현 | 정보 배치 | 적합한 점 |
| --- | --- | --- | --- |
| A 산뜻한 우리동네 | 민트, 직접 그린 동네 그래픽 | 현재 단계, 챙길 일, 보조 기능 | 주민 친화성과 가독성의 균형, 추천 |
| B 다정한 생활 안내 | 살구색, 이사 상자와 안내문 그림 | 생활 안내 제목, 단계 카드, 챙길 일 | 부담을 낮추는 생활 서비스 인상 |
| C 한 걸음 길잡이 | 파랑, 이전/현재/다음 경로 | 단계 흐름, 행동 카드, 보조 기능 | 진행 위치와 다음 행동의 선명한 구분 |

B는 큰 카드와 여백을 사용해 첫 화면의 정보량이 적습니다. C는 전체 단계 중 인접한 세 단계만 보여주며 전체 단계 버튼으로 나머지를 확인합니다. A의 단계 막대는 단계의 순서이며 공정률, 소요 기간, 사업 성공 확률이 아닙니다.

## 사용자 여정

구역 선택 → 거주 유형 선택 → 현재 단계 확인 → 챙길 일 확인 → 조건과 근거 확인 → 질문 또는 문서 사진 확인.

이번 시안은 그중 내 구역과 챙길 일 화면을 구현했습니다. 나머지 기능 버튼은 시안 범위를 설명하는 패널로 연결합니다. 실제 답변 생성이나 업로드, 기기 저장은 수행하지 않습니다.

## 기존 코드 진단

- 현재 타임라인은 전체 단계와 이벤트를 표시한 뒤 주요 행동이 나옵니다. 필요한 행동에 도달하기까지 읽어야 하는 분량이 많습니다.
- 네이비 헤더, 반복 카드, 작은 배지가 중심이라 시각적 차별성이 약합니다.
- 홈 아이콘은 주거보다 공장으로 읽힐 가능성이 있습니다.
- 문서 사진 기능은 하단 메뉴에서 직접 드러나지 않습니다.
- 이번 시안에서는 현재 단계와 행동 버튼을 앞쪽에 두고, 전체 단계와 근거를 별도 패널로 분리했습니다.

위 진단은 소스코드 검토 기준입니다. 실제 앱의 개선 전 캡처나 API 통합 검증은 이번 방향 선택 단계에서 수행하지 않았습니다.

## 내용과 신뢰 장치

데이터 출처는 content/zones/sujin1.yaml, content/stages.yaml, content/checklists/tenant.yaml입니다. 공공 트랙의 RELOCATION은 11단계 중 8번째입니다. 안내 제목과 본문은 해당 YAML의 문구를 유지했습니다. 체크리스트에는 디자인 비교를 위해 두 항목만 표시합니다.

저장소 콘텐츠를 사용했으며 이 작업에서 법령 원문이나 구역 현황을 외부에서 재검증하지 않았습니다. 법적 해석을 새로 만들지 않았습니다. 원문 인용 전문은 시안에 복사하지 않았고, 근거 패널에서 국가법령정보센터로 연결합니다. 전체 근거 인용과 고시 연결은 실제 제품 적용 때 기존 기능과 통합해야 합니다.

데이터 기준일과 법률, 투자 자문 고지를 유지했습니다. 그림은 상징적 삽화이며 수진1구역의 실제 건물, 경계 또는 완공 계획을 묘사하지 않습니다.

## 모션과 접근성

SVG 그림은 450ms 동안 부드럽게 등장합니다. C의 현재 위치는 두 차례만 강조됩니다. 버튼을 누르면 짧은 눌림 효과가 적용됩니다. prefers-reduced-motion 환경에서는 모션을 끕니다.

본문 18px, 큰 글씨 상태의 안내 본문 21px, 주요 버튼 54px, 보조 버튼 48px를 기준으로 했습니다. 보조 레이블은 13~16px입니다. 근거 패널은 초점 이동, Tab 순환, Escape 닫기, 이전 버튼으로 초점 복귀를 지원합니다.

기존 큰 글씨 모드 전체 토큰 적용, 모든 텍스트 대비의 전수 측정, 실제 모바일 보조기술 검증은 제품 구현 단계에 남아 있습니다. 이번 검사 통과를 제품 접근성 인증으로 해석하지 않습니다.

## 후속 체크리스트: 점진적 공개

checklist-disclosure.html은 A 구성과 B 색상 조합에서 체크리스트의 최초 노출 분량을 줄인 별도 시안입니다. 안내 제목, 예외 및 지원 조건을 항상 표시하고 전체 검수 문장은 자세히 보기로 펼칩니다. 법적 근거는 별도 버튼으로 한 번에 확인합니다. 기존 a-peach 시안은 비교를 위해 보존했습니다. 체크박스는 실제 조치를 완료했다는 오해를 만들 수 있어 추가하지 않았습니다.
